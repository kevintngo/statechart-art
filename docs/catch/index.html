What TLC checked

TLC, a model checker, tried every way this model of the flight can go: 88 states and 132 steps, with the booster, the ship and the tower changing side by side, sometimes in the same step.

  • Holds: the arms close only when a booster is coming in to them.
  • Holds: the booster turns back only after the ship is free.
  • Holds: the flight never gets stuck.
  • Breaks if the go/no-go poll is skipped and the booster comes in by default: a booster with a failed check heads for the tower anyway (5 steps), and then it hits the tower (7 steps).

The poll is the guard. With it, a failed check sends the booster to the sea instead. On real flights the sea is the default: the booster comes in only if every check passes and the flight director calls “go” before the boostback burn ends.

Every state each part can be in, and every step between them, stitched into one sampler. Gold is the flight that works. Red is where the path TLC found goes wrong when the go/no-go poll is skipped, and a small red knot marks each state on that path. Grey is every other way it can go.
